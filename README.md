# 読書メモ

読書中の思いつき・フレーズ・問いをiPhoneから数秒で記録し、過去の読書と「再会」させる個人用のWebアプリ(PWA)。

## 特徴

- **サーバーなし・運用費0円**: データはiPhoneの中(IndexedDB)だけに保存する。アプリ本体は静的ファイルとして配信する。
- **媒体ごとの位置**: 紙はページ、電子書籍は位置No.または%、オーディオブックは再生時刻で記録する。
- **再会**: メモを保存すると、書名やメモに共通する語から、関連しそうな過去の本やメモを出す。「つなげて一言」で書いたメモは、今の本と過去の本の両方に残る。計算は端末内の文字2-gram TF-IDFで、外部に送らない。
- **ブクログ取り込み**: ブクログの本棚エクスポートCSV(Shift_JIS・ヘッダなし・17列)を読み込む。二重登録はしない。
- **書影**: 国立国会図書館サーチの書影(ISBNがある本)→Amazonの商品画像(ブクログのアイテムID=ISBN10/ASIN、Kindle本も)の順に `<img>` で直接試し、読めたURLを本に保存する。どれもなければGoogle Booksに1冊ずつ問い合わせる。
- **日付と並び順**: 本ごとに登録日・読み始めた日・読了日を記録・修正できる(ブクログの登録日と読了日は取り込み時に入る)。本棚は登録日・読了日・刊行日で並び替えられ、向きも切り替えられる。
- **評価**: 本の詳細でスライダーを使い10点満点で付ける(ブクログの5段階は2倍して換算)。本棚は評価順にも並べられる。
- **分析**: 読了冊数(年・月のヒートマップ)、刊行から読了までの年数とその推移、ページ数の分布と推移、媒体の内訳、よく読む著者、評価の分布。期間(全期間/10年/5年/今年)で絞り込め、各グラフに表の表示がある。
- **カテゴリ**: 一覧は設定で編集(1行1つ)。本の詳細で選ぶか、設定の「未分類の本をまとめて分類」でNDC→Gemini(書名と著者名だけを送る、100冊ずつ)で一括分類。本棚と分析をカテゴリで絞り込め、分析にカテゴリ別の冊数・年ごとの割合・読み方の比較がある。
- **関連する本**: 本の詳細の「関連する本を探す」で、Geminiが「近い/遠いのに通じる/反対側から」の3観点で提案(キーがなければ国会図書館サーチの件名で探す)。各本にAmazonの検索リンクと「読みたい」ボタン。結果は本に保存し、読みたいに入れた本には「きっかけ」が残る。
- **読みたいの一本化**: 本を追加画面の「読みたい本をまとめて追加」に、図書館の予約一覧やAmazonのほしい物リストをコピーしたもの、AmazonのURL、ISBN、書名を貼ると、照合して一覧にし、選んだ本を入手先付きで「読みたい」に入れる。本の詳細で入手先(図書館・Amazon・積読など)を変えられる。
- **図書館の貸出状況**: カーリルAPI(無料キー)で、設定した図書館(既定は吹田市立図書館 Osaka_Suita)の蔵書と貸出状況を確認し、予約ページへのリンクを出す。読みたいの一覧からまとめて確認もできる。
- **概要**: 本の詳細に概要を出す。openBD→Google Books→国立国会図書館サーチの注記→Wikipediaの作品記事の順に探し、取れたものを本に保存する。
- **関連リンクと著者**: YouTube・書評サイト・X(感想と著者の検索)・映像化情報・図書館への検索リンク、Wikipediaの著者概要、本棚にある同じ著者の本、Google Books(使えなければ国立国会図書館サーチ)による未読の作品一覧(「読みたい」に追加できる)。
- **Google Books APIキー(任意)**: キーなしの呼び出しは全利用者で1日の上限を共有していて、よく429で止まる。設定に自分のキーを入れると安定する。設定の「接続を確かめる」で各サービスに届くかを確認できる。
- **AIと考える(任意)**: 自分のGemini APIキーで「問い返す」「反論する」「橋を架ける」を呼ぶ。押したときだけ送信する。
- **バックアップ**: JSONに書き出して共有シートから「ファイル」(iCloud Drive)へ保存する。APIキーは書き出さない。
- **圏外でも使える**: Service Workerでアプリ本体をキャッシュする。

## 使い方(iPhone)

1. 配信URLをSafariで開き、共有ボタンから「ホーム画面に追加」する。追加しないとSafariが保存データを消すことがある。
2. 設定 → ブクログから取り込む で、ブクログのCSVを選ぶ。
3. 本棚 → 本を追加 で読む本を登録し、記録タブから書く。音声はキーボードのマイクを使う。
4. 設定 → バックアップ で、ときどき書き出す。

## 開発

ビルド不要。ES Modulesのまま配信する。

```sh
npm run serve   # http://localhost:8765
npm test        # Node 20以降
```

| ファイル | 役割 |
|---|---|
| `js/app.js` | 画面とルーティング |
| `js/db.js` | IndexedDBの薄いラッパー |
| `js/booklog.js` | ブクログCSVの読み込み |
| `js/related.js` | 関連検索(文字2-gram TF-IDF) |
| `js/categories.js` | カテゴリの既定一覧、NDCからの対応、Geminiでの一括分類の入出力 |
| `js/discover.js` | 関連する本の提案(Geminiへの指示と返答の読み取り、Amazon検索リンク) |
| `js/wantimport.js` | 読みたいの貼り付け取り込み(URL・ISBN・一覧の文字を読み取る) |
| `js/calil.js` | カーリル図書館APIで蔵書と貸出状況を確認(JSONP) |
| `js/stats.js` | 分析画面の集計とグラフ(手書きSVG、ライブラリなし) |
| `js/books.js` | 書誌検索(Google Books、国立国会図書館サーチ) |
| `js/gemini.js` | Gemini API呼び出し |
| `js/backup.js` | JSONの書き出し・読み込み |
| `css/hig-*.css` | Apple HIGに沿ったデザイントークンと部品 |

書誌と書影に国立国会図書館サーチのAPI、Google Books API、WikipediaのREST APIを利用し、書影にAmazonの商品画像を表示しています(いずれもAPIキー不要、Google Booksはキーを任意で設定可)。
